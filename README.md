# NovaFX Studio — Android starter

This is the first starter build of NovaFX Studio. It creates a dark Compose-based Android app shell.

## Build
- Android Studio
- JDK 17
- Android SDK 35
- Gradle 8.9 (wrapper recommended)

Open this folder in Android Studio and let Gradle sync. Then run the `app` configuration on an Android device or emulator.

## Current status
This starter contains the app shell and workspace preview only. It is **not yet** a professional editor. Media import, playback, timeline editing, effects, keyframes, AI features and export will be implemented in later stages.
